# Teams Meeting Recorder

Windows-приложение для **автоматической локальной записи** совещаний Microsoft Teams: захватывает окно встречи и системный звук, сохраняет MP4-файлы на диск.

## Важно: согласие участников

Запись совещаний без уведомления и согласия участников может нарушать:

- законодательство вашей страны (персональные данные, тайна связи);
- политику компании и Microsoft Teams;
- трудовые и GDPR-требования.

**Перед использованием** убедитесь, что у вас есть право записывать встречи, и **сообщайте участникам** о записи.

## Возможности

- Автообнаружение активной встречи Teams через UI Automation (не зависит от заголовка окна).
- Если программа запущена **во время уже идущей встречи**, запись начнётся автоматически в течение ~1–2 секунд.
- Запись окна встречи + системного аудио (WASAPI loopback).
- Автостарт при входе во встречу, автостоп после выхода (~6 сек debounce).
- Иконка в системном трее: статус, пауза, открытие папки записей.
- Настройки через `config.yaml`.

## Требования

- Windows 10/11
- Python 3.10+
- Microsoft Teams (desktop, `ms-teams.exe`)
- FFmpeg в PATH **или** пакет `imageio-ffmpeg` (устанавливается через pip)

## Установка

```powershell
cd d:\newsite
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### FFmpeg (рекомендуется)

1. Скачайте FFmpeg: https://ffmpeg.org/download.html
2. Добавьте `ffmpeg.exe` в PATH

Если FFmpeg не установлен, приложение попробует использовать bundled-версию из `imageio-ffmpeg`.

## Запуск

```powershell
python main.py
```

После запуска в трее появится иконка:

- **серая** — ожидание встречи;
- **красная** — идёт запись.

Меню:

- **Пауза авто-записи** — не начинать новые записи (текущая продолжится до конца встречи).
- **Открыть папку записей**
- **Открыть последнюю запись**
- **Выход**

Записи сохраняются в папку `./recordings` (настраивается в `config.yaml`).

Формат имени файла: `YYYY-MM-DD_HH-MM_НазваниеВстречи.mp4`

## Настройка (`config.yaml`)

```yaml
output_dir: "./recordings"
poll_interval_sec: 2
stop_debounce_checks: 3
video_fps: 20
video_crf: 23
include_microphone: false
autostart_with_windows: false
```

| Параметр | Описание |
|---|---|
| `output_dir` | Папка для MP4-файлов |
| `poll_interval_sec` | Интервал проверки встречи (сек) |
| `stop_debounce_checks` | Сколько проверок подряд без встречи перед остановкой |
| `video_fps` | Частота кадров (15–30) |
| `video_crf` | Качество видео H.264 (меньше = лучше, 18–28) |
| `include_microphone` | Зарезервировано (микрофон в MVP не используется) |

## Автозапуск с Windows

1. Создайте ярлык на `pythonw.exe main.py` (или `.venv\Scripts\pythonw.exe main.py`).
2. Поместите ярлык в:

```
%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup
```

Либо установите `autostart_with_windows: true` в config и создайте ярлык вручную (MVP не создаёт ярлык автоматически).

## Как это работает

1. Каждые 2 секунды приложение ищет окно Teams с элементами встречи (`microphone-button`, кнопка выхода).
2. Окна «на удержании» (кнопка Resume) пропускаются.
3. При обнаружении встречи запускаются:
   - захват кадров окна (PrintWindow);
   - захват системного звука (WASAPI device loopback, не per-app — Teams desktop иначе даёт тишину).
4. FFmpeg кодирует видео и mux-ит с аудио в MP4.

## Устранение неполадок

| Проблема | Решение |
|---|---|
| Запись не начинается | Убедитесь, что вы **в активной встрече** (не в лобби). Проверьте, что Teams — desktop-приложение. |
| Нет звука в записи | Проверьте, что звук воспроизводится через колонки/наушники. Перезапустите приложение. |
| FFmpeg not found | Установите FFmpeg или `pip install imageio-ffmpeg` |
| Высокая нагрузка на CPU | Уменьшите `video_fps` и увеличьте `video_crf` в config |
| Teams обновился | Возможно, изменились UI-элементы — обновите селекторы в `src/detector.py` |
